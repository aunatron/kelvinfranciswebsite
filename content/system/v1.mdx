One operator, one machine, one loop. The judgment never delegates; the memory
never sleeps. **The daily architecture runs in three phases:**

- **PHASE 1** — Brain dump — 10 minutes, unformatted, no filtering.
- **PHASE 2** — Machine triage — sorted into Urgent Today / Delegate / Save for Later.
- **PHASE 3** — Single-focus execution — one thing, closed, before the next.

The machine holds the state so the human can hold the line. **That's the
whole system.**
